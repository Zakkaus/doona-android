# doona-core contract fixtures

Example payloads for `plans/v1/core-api.md` (schema 1), parsed by the Rust tests in `crates/doona-core` and by a Kotlin JVM test of `vpn/CoreDto.kt`. Change them together with both sides. The two `hk-01` nodes are distinct endpoints with the same display name, and the second one's probe failed with `local_network`; the running snapshot carries the `local_network` warning, and the stopped one kept no yesterday (`yesterdayByNow` null); the subscription URL's token is a placeholder. The stats replies use one invented day, 2026-11-22: a five-second rate window, today and yesterday by the hour with each outbound's payload, the daily totals (2026-11-20 had no bytes, so it is absent), and two nodes' details with their latency tests, one of them failed.
